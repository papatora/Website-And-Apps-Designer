# Website-And-Apps-Designer

A kit for building websites and apps that look designed, not generated:
skins (design tokens), templates, a component layer, reference docs, and
zero-dependency Node tools.

## Layout
- `tokens/base.css` — scales (space, type, radius, motion). No colors.
- `skins/*.css` — one file per skin, scoped to `[data-skin="id"]`, colors as `light-dark(#light, #dark)`. Contract in `skins/_template.css`. Metadata in `skins/registry.js`.
- `components/components.css` — reads only skin variables + tokens. No raw colors.
- `templates/<name>/index.html` — plain HTML; preview any skin with `?skin=<id>`.
- `docs/` — design guidance. `docs/research.md` holds the sources (Anthropic, Impeccable, Hallmark, Fudge) and `docs/anti-slop.md` the rules derived from them.
- `tools/` — `slop-lint.mjs`, `find-reference.mjs` (searches the Fudge real-site guides), `contrast-check.mjs`, `export-tokens.mjs`, `new-project.mjs`, `layout-check.mjs`, `serve.mjs`.
- `tokens/figma/*.json` — generated by `npm run tokens`; never edit by hand.
- `adapters/tailwind/` (v4 `theme.css`, v3 `preset.cjs`) and `adapters/react/index.jsx`.
- `.claude/skills/` — `anti-slop-design`, `design-review`, `scaffold-site`.

## Commands
- `npm run dev` — preview server at http://localhost:4321
- `npm run check` — tests + contrast + token freshness + slop-lint (must pass before committing)
- `npm run tokens` — regenerate `tokens/figma/` after changing any skin
- `npm run check:layout` — every template × skin at 390px and 1440px in Chromium (needs Playwright)
- `npm run new -- --template landing --skin studio --out ../site`

## Conventions
- No build step, no runtime dependencies. Node ≥ 18 for tools.
- Adding a skin: find a real reference first (`node tools/find-reference.mjs`), copy `_template.css`, fill every variable (including `--field`), add it to `registry.js` with its `reference`, add a `<link>` in `index.html`, run `npm run tokens` and `npm run check`. It must not sit in one of the default clusters listed in `docs/research.md`.
- Adding a template: link tokens → skin (`id="skin-css"`) → components, include `registry.js` and `_shared/skin-switcher.js`, write real copy, and add it to the gallery in `index.html`.
- New slop-lint rules need a source (add it to `docs/research.md`), a `src` key, a case in `tests/fixtures/sloppy.html`, and must not fire on `tests/fixtures/clean.html`.
- No decorative eyebrow labels, `·` meta strings, `WORD — fragment` labels, glyph icons or drawn device chrome in templates. Mark sample figures as fictional in a comment at the top.
- Templates must lint at 0 errors and 0 warnings and pass `check:layout`.
- Grid containers that hold tables, code or nowrap content need `minmax(0, 1fr)` columns, and mobile media queries must come after (or out-specify) the rules they override — both caused real overflow bugs here.
