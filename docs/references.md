# References & tools

A short, curated list. Everything here is something you'll actually open.

## Type
- [Google Fonts](https://fonts.google.com) · [Fontshare](https://www.fontshare.com) (free, characterful) · [Collletttivo](https://www.collletttivo.it) (free, experimental)
- [Typewolf](https://www.typewolf.com) — what fonts real sites use · [Fonts In Use](https://fontsinuse.com)
- [Utopia](https://utopia.fyi) — fluid type & space calculators · [Modern Font Stacks](https://modernfontstacks.com)

## Color
- [oklch.com](https://oklch.com) · [Huetone](https://huetone.ardov.me) · [Leonardo](https://leonardocolor.io) · [Realtime Colors](https://www.realtimecolors.com)
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) · [APCA](https://apcacontrast.com)

## Layout & CSS
- [Every Layout](https://every-layout.dev) · [SmolCSS](https://smolcss.dev) · [Open Props](https://open-props.style) · [Modern CSS Solutions](https://moderncss.dev)

## Components & patterns
- [Radix Primitives](https://www.radix-ui.com) · [shadcn/ui](https://ui.shadcn.com) (restyle it — the defaults are now a tell) · [Inclusive Components](https://inclusive-components.design)
- [Laws of UX](https://lawsofux.com) · [Refactoring UI](https://www.refactoringui.com) (book)
- [Apple HIG](https://developer.apple.com/design/human-interface-guidelines) · [Material 3](https://m3.material.io) — for native-feeling apps

## Icons
- [Lucide](https://lucide.dev) · [Phosphor](https://phosphoricons.com) · [Tabler](https://tabler.io/icons) · [Heroicons](https://heroicons.com)

## Motion
- [cubic-bezier.com](https://cubic-bezier.com) · [easings.net](https://easings.net) · [Motion](https://motion.dev)

## Inspiration (real, curated sites)
- [Mobbin](https://mobbin.com) — real app screens · [Godly](https://godly.website) · [Minimal Gallery](https://minimal.gallery) · [SiteInspire](https://www.siteinspire.com) · [Land-book](https://land-book.com)
- Tip: study sites from **studios and publications**, not SaaS templates. Pentagram, Klim Type Foundry, Stripe Press, The Pudding, Linear's changelog.
