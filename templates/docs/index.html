Reference / Matches

Create a match

Links one bank transaction to one receipt. Use this when your own system already knows the pairing — Ledgerline's overnight matcher will leave it alone.

POSThttps://api.ledgerline.example/v2/matches

Body parameters

NameTypeDescription
transaction_idrequiredstringID of the bank transaction, e.g. txn_8Kd2…
receipt_idrequiredstringID of an uploaded receipt, e.g. rcp_Q41m…
vat_ratenumberOverrides the VAT rate read from the receipt. Percent, 0–27.
notestringShown to your accountant in the export. Max 280 characters.

Example

curl
curl https://api.ledgerline.example/v2/matches \
  -H "Authorization: Bearer $LEDGERLINE_KEY" \
  -H "Idempotency-Key: 5f1c7e2a-match-0142" \
  -d transaction_id=txn_8Kd2Lr0v \
  -d receipt_id=rcp_Q41mZt7b \
  -d vat_rate=21
Response: 201 Created
{
  "id": "mch_3Hq9Fz",
  "transaction_id": "txn_8Kd2Lr0v",
  "receipt_id": "rcp_Q41mZt7b",
  "amount": -142.60,
  "currency": "EUR",
  "source": "api"  // "auto" when created by the overnight matcher
}
Amounts must agree within €0.05. Larger differences (tips, partial refunds) return amount_mismatch; pass note and set force=true to record them anyway.

Errors

StatusCodeWhat to do
404transaction_not_foundCheck the ID belongs to this workspace.
409already_matchedDelete the existing match first, or ignore if you're retrying.
422amount_mismatchSee the note above.
